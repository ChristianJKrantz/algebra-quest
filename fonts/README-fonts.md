# Fonts

- **Fraunces** (fraunces-*.woff2), unmodified. SIL Open Font License 1.1, see OFL-Fraunces.txt.
- **AQ Legible** and **AQ Legible Mono** (aq-legible-*.woff2) are modified versions of Atkinson Hyperlegible Next and Atkinson Hyperlegible Mono. The slash was removed from the zero so it can't be mistaken for the empty-set symbol ∅ in algebra. Renamed per the SIL Open Font License 1.1; see OFL-AtkinsonHyperlegibleNext.txt and OFL-AtkinsonHyperlegibleMono.txt.
