# Fonts

All fonts are under the SIL Open Font License 1.1; license files are in this folder.

- **Fraunces** (fraunces-*.woff2), headings. OFL-Fraunces.txt.
- **Source Serif 4** (source-serif-4-*.woff2), reading text. OFL-SourceSerif4.txt.
- **Inter** (inter-*.woff2), labels and buttons. OFL-Inter.txt.
- **AQ Legible Mono** (aq-legible-mono-*.woff2), typed answers. A modified version of Atkinson Hyperlegible Mono: the slash was removed from the zero so it can't be mistaken for the empty-set symbol ∅. Renamed per the license; see OFL-AtkinsonHyperlegibleMono.txt.
